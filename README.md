# 周易数字典藏（ZhouYi）

Android 原生离线古籍阅读与版本资料典藏项目。

## 当前版本

开发预览版 0.1.0。当前已建立 Kotlin Android 工程、基础阅读界面、分类筛选、全文搜索和 GitHub Actions APK 构建流程。

首批录入内容：
- 《周易》六十四卦通行本经文：卦辞、六条爻辞；乾卦“用九”、坤卦“用六”一并收录；
- 每卦单独标明底本文字来源与校勘状态；逐段译文暂标“暂无可靠译文”，不以未经核验的机器释义充数；
- 洛书专题扩充：后世通行九宫图、刘牧《易数钩隐图》五行生数/成数、十日生五行、河图九数与洛书十数的名称易位；
- 洛书九宫、五行生数、五行成数三组本地矢量示意图，明确标注“现代重绘、非古籍原图”；
- 《周易·系辞上传》“河出图，洛出书”相关段落；
- 《尚书·洪范》九畴节录及其与洛书关系的文献边界说明；
- 河图专题资料边界；
- 敦煌本《周易》资料档案索引。

## 严格文本原则

- 不根据上下文补写缺文、残字或失传图像。
- 通行图式、古籍原图、现代复原图必须区分。
- 传世文献原文与后世解释分开标注。
- 未核实的译文、异文、年代和来源明确标记。
- 版本校勘须记录底本、参校本、卷次、位置及依据。

## 构建 APK

推送到 main 或在 Actions 页面手动运行 Android APK 工作流后，会构建 app-debug.apk，并上传名为 ZhouYi-debug-apk 的 artifact。

环境要求：JDK 17、Android SDK API 35、Gradle 8.9。

本地构建：gradle assembleDebug

APK 输出：app/build/outputs/apk/debug/app-debug.apk

## 洛书专题本批资料来源与图像说明

- 刘牧《易数钩隐图》卷下，含“河图第四十九”“洛书五行生数第五十三”“洛书五行成数第五十四”“十日生五行并相生第五十五”及《龙图龟书论》：<https://www.shidianguji.com/book/DZ0159/chapter/DZ0159_58>；四库本卷下：<https://zh.wikisource.org/zh-hans/易數鈎隱圖_(四庫全書本)/卷下>。
- 张克宾：《论刘牧〈河图〉〈洛书〉说的架构与意蕴》，《周易研究》2024年第4期，山东大学易学与中国古代哲学研究中心页面及论文图版：<https://zhouyi.sdu.edu.cn/info/1034/1725.htm>。
- 该论文对刘牧图式的分析指出：刘牧以九数图为河图、五行生成数为洛书；其洛书由五行生数图与成数图分别呈现，并未合为一张总图。后世通行的河图五十五数、洛书九宫四十五数与刘牧系统的图名配置不同。
- 本应用中的九宫图及五行生数/成数图为重新绘制的本地矢量示意图，旨在准确呈现数字与五行对应关系；不冒充古籍原图。论文所刊图13、图14及识典古籍所列图像入口保留为外部图版核验线索。未经授权的期刊扫描图不直接打包进 APK。

### 图版入库规则

- 每张图保存原书名、作者/编者（不详则标不详）、版本、卷次、原书页码、馆藏、扫描来源、授权说明和对应正文位置。
- 先保留原页全貌，再制作适合手机显示的裁切副本；不覆盖原图。
- 图像只在确实对应经文、传文、卦或某一易学论说时关联；不能只因主题相近就硬挂到某卦。
- 原图、后世摹刻、现代复原图分开显示；不清楚的版次和图名明确标待考。
- 优先使用明确公有领域或许可允许再利用的图像。授权不明的扫描只记录来源，不打包分发。
- 图像离线资源尚未完成抽取和打包前，不标记为“已收录原图”。
