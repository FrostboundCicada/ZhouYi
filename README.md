# 《周易》数字典藏

本项目是以《周易》经传为核心的离线古籍阅读与研究资料整理工程。当前主要内容位于：

- `app/src/main/java/org/frostboundcicada/zhouyi/MainActivity.kt`

## 文本整理原则

1. 原文、注文、疏文、校记和现代说明分层呈现，不把注家解释混写成经文。
2. 缺文、残字、漫漶和无法核实的内容保留缺失状态，不依据上下文补造。
3. 异文并列标注来源；尚未完成版本核验的条目明确说明核验边界。
4. 摘录、索引和内容提要不得标作全本或全文。
5. 古籍原图、影印图、摹本和现代重绘须分别标识；文字目录不代表图像已经嵌入。
6. 翻译是辅助阅读文本，不替代底本和校勘。

## 翻译字段说明

阅读页面区分两类内容：

- **原有译文 / 内容说明**：保留条目原有的 `translation` 字段。该字段可能是已有译文，也可能是译注、内容状态或说明；在未逐条核实之前，不自动认定为可靠译本。
- **ChatGPT 翻译（工作译文）**：`chatGptTranslation` 字段，由 ChatGPT 根据条目所录原文独立翻译。该译文明确标记为 ChatGPT 翻译，不冒充权威译本。

如果条目没有足够完整、可辨识的原文，不能仅凭标题或摘要生成“全文译文”；应先补齐并核验原文。遇到异文、疑难训诂和残缺时，译文须保留不确定性说明。
