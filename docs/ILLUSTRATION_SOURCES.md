## 离线打包准入规则

1. 每张图必须记录书名、版本、卷次、原书叶码／扫描页码、馆藏机构、来源 URL、许可声明和校验值。
2. 优先保留原始整页扫描；阅读用裁切图必须能反向定位到整页母图。
3. 只有明确许可允许再利用的图像才复制进 APK；授权不清楚的只保留外部来源链接。
4. 不以 OCR、目录文字或现代矢量重绘替代古籍原图。
5. 图像与卦爻、十翼章节的对应关系必须逐项核对；无法确认时标记“待考”，不猜配。
6. 当前版本仍未包含上述来源的离线原图文件。此清单和应用内链接不应被宣传为“原图已离线集成”。
